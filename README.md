# Happy Birthday Khushi

A dark cosmic luxury Birthday Celebration website built for **Khushi**. Featuring an interactive virtual cake with candle blowing, real-time shared guestbook wish wall, dynamic celebrations, and background birthday music.

---

## Features

- **Interactive Virtual Cake:** 3-tier cosmic neon cake with interactive candles that you can blow out or click. Includes pentatonic chime synthesis and confetti fireworks.
- **Personalized Birthday Card:** Special wish revealed upon blowing the candles.
- **Shared Live Guestbook:** Leave your heartfelt birthday wishes with custom stamp icons that show up in real-time for everyone visiting the website.
- **Atmospheric Background Music:** Plays celebratory birthday music smoothly in the background.
- **Cosmic Luxury Design:** Deep space navy palette (`#010828`), neon accents, glassmorphism UI, and fluid animations. Zero emojis, pure Lucide icons.

---

## Tech Stack

- **Framework:** TanStack Start (React 19 + Vite)
- **Styling:** Tailwind CSS v4
- **Animation:** Framer Motion & Canvas Confetti
- **Icons:** Lucide React
- **Language:** TypeScript
- **Deployment:** Vercel

---

## Getting Started

```bash
# install dependencies
pnpm install

# start dev server
pnpm dev

# build for production
pnpm build
```
